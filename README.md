# 📄 ResuméCraft

A modern, responsive resume builder built with React that allows users to create professional resumes using customizable templates, real-time previews, and PDF export.

🌐 **Live Demo:** [ResuméCraft](https://resume-builder-sigma-ivory-20.vercel.app/)

🔗 **GitHub Repository:** [resume-builder](https://github.com/kenil948/resume-builder)

---

## ✨ Features

### 📑 Resume Templates

- Choose from five templates: Classic, Modern, Creative, Minimal, and Executive.
- Explore different layouts for presenting professional information.
- Customize formatting according to your preferences.

### ✏️ Resume Editing

- Add and edit personal information.
- Manage education and work experience.
- Add skills and professional summaries.
- Dynamically manage form sections.

### 🎨 Formatting Customization

- Customize fonts and font sizes.
- Change text colors and formatting styles.
- Adjust text alignment.
- Maintain independent formatting for different templates.
- Restore saved formatting when switching between templates.

### 👁️ Live Preview

- Preview resume changes while editing.
- View the selected template in the preview panel.
- Adjust the preview using responsive layouts and zoom controls.

### 📥 PDF Export

- Print or save resumes as PDF files.
- Preview the resume before exporting.
- Generate printable resumes directly through the browser.

### 📱 Responsive Design

- Responsive interface for desktop, tablet, and mobile.
- Adaptive editor and preview layouts.
- User-friendly navigation across screen sizes.

### 💾 Data Persistence

- Save resume information in browser local storage.
- Preserve template selection and formatting preferences.
- Retain supported saved data between page reloads without requiring a backend database.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kenil948/resume-builder.git
```

### Navigate to the Project

```bash
cd resume-builder
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will be available at the local URL displayed in your terminal, typically:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Run the linter:

```bash
npm run lint
```
